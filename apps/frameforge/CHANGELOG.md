# آخرین تغییرات فریم‌فلو

این فایل فقط ۱۵ نسخهٔ آخر تغییرات این اپ را نگه می‌دارد؛ با ثبت نسخهٔ شانزدهم، قدیمی‌ترین نسخه حذف می‌شود.

## PR شماره ۱۹

- نسخهٔ نخست اپ مستقل فریم‌فلو با ورودی ۴ تا ۳۶ تصویر ساخته شد.
- برش خودکار شیت بر اساس ردیف و ستون، انتخاب و ترتیب فریم‌ها و پخش با FPS قابل تنظیم اضافه شد.
- لایه‌بندی صحنه، تبدیل همزمان تمام فریم‌های کاراکتر و خروجی JSON تنظیمات پروژه پیاده‌سازی شد.
