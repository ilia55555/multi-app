# فریم‌فلو

فریم‌فلو یک اپلیکیشن مستقل و کاملاً مرورگرمحور برای آماده‌سازی انیمیشن‌های دوبعدی است. تصاویر فقط در حافظهٔ مرورگر خوانده می‌شوند و به سروری فرستاده نمی‌شوند.

## قابلیت‌ها

- ورود حداکثر ۳۶ تصویر PNG، JPEG یا WebP و انتخاب فریم‌های فعال.
- برش یک Sprite Sheet به شبکه‌ای از ۱ تا ۶ ردیف و ستون.
- تغییر ترتیب فریم‌ها با کشیدن و رهاکردن و پخش با سرعت ۱ تا ۳۰ FPS.
- افزودن تصویرهای ثابت به‌عنوان پس‌زمینه، مانع یا کاراکتر دیگر در لایه‌های مستقل.
- تنظیم موقعیت، مقیاس، چرخش و شفافیت هر لایه؛ تنظیم لایهٔ کاراکتر روی تمام فریم‌ها اعمال می‌شود.
- دریافت JSON شامل ترتیب فریم‌ها، سرعت و حالت پخش، ابعاد صحنه و تبدیل لایه‌ها.

## اجرا

فایل `index.html` را از طریق وب‌سرور استاتیک پروژه باز کنید. برای استفادهٔ کامل، حداقل ۴ تصویر وارد کنید؛ پیش‌نمایش با تعداد کمتر نیز برای آماده‌سازی پروژه فعال است.
