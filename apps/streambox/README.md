# StreamBox / استریم باکس

اپ مستقل پخش ویدیو از لینک مستقیم است. مرورگر دادهٔ ویدیو را به‌صورت تدریجی دریافت و همزمان پخش می‌کند. آخرین زمان تماشا در `localStorage` ذخیره می‌شود و دکمهٔ تلاش مجدد پس از اختلال، ویدیو را از همان موقعیت ادامه می‌دهد.

این اپ بدون فریم‌ورک و وابستگی و فقط با فایل‌های `index.html`، `styles.css` و `app.js` اجرا می‌شود.

## پیش‌نیاز لینک

- پروتکل `http` یا `https`
- فرمت قابل پخش در مرورگر، ترجیحاً MP4 (H.264) یا WebM
- پشتیبانی سرور فایل از HTTP Range برای جابه‌جایی و ادامهٔ مطمئن

## مرزبندی تغییرات

درخواست‌هایی که مشخصاً مربوط به StreamBox هستند فقط باید این اپ و اتصال آن به پوستهٔ مرکزی را تغییر دهند؛ سایر اپ‌ها مستقل باقی می‌مانند.
