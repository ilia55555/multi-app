# RigidMesh Studio / استودیو مش صلب

ابزار مستقل مرورگری برای واردکردن مدل کاراکتر و جابه‌جایی یا چرخاندن **آبجکت‌های Mesh به‌شکل صلب** است. این برنامه موقعیت و چرخش آبجکت انتخابی را تغییر می‌دهد و رأس‌های هندسه را ویرایش نمی‌کند؛ مقیاس نیز در رابط قفل است تا کشیدگی ناخواسته ایجاد نشود.

## فرمت‌ها و محدودیت‌ها

- `GLB` برای مدل‌های کامل و دارای بافت پیشنهاد می‌شود.
- `GLTF` فقط وقتی منابع آن داخل همان فایل جاسازی شده باشند قابل بارگذاری است.
- `OBJ` هندسه را بارگذاری می‌کند؛ فایل‌های جانبی MTL و بافت همراه آن خوانده نمی‌شوند.
- سقف فایل ورودی ۵۰ مگابایت است.
- مدل باید برای هر عضو قابل‌حرکت، یک Mesh جدا داشته باشد. این ابزار رأس‌ها، اسکین، وزن‌های استخوانی یا توپولوژی را ویرایش نمی‌کند.

## کنترل‌ها

- کلیک روی مدل یا نام بخش: انتخاب Mesh
- `W`: ابزار جابه‌جایی
- `E`: ابزار چرخش
- `Ctrl/Cmd + Z`: واگرد
- `Ctrl/Cmd + Shift + Z`: بازانجام
- خروجی: فایل باینری `GLB` با تبدیل‌های فعلی

Three.js و افزونه‌های رسمی آن از CDN بارگذاری می‌شوند؛ بنابراین نخستین اجرا به اتصال اینترنت نیاز دارد.
