# SFX Studio — استودیو افکت صدا

استودیوی کوچک ساخت و ویرایش افکت صوتی برای بازی (شلیک، برخورد گلوله، انفجار، خشاب، پوکه و…).

- **سازنده:** ۱۸ پریست بازی، موج/فرکانس/اسلاید/ویبراتو، پوش صدا، نویز، لایه بم، فیلتر جاروب‌شونده، دیستورشن و بیت‌کراش؛ امکان درج یا میکس لایه‌ها روی هم.
- **ورودی:** آپلود هر فرمت صوتی مرورگر، Drag & Drop، ضبط میکروفون و بارگذاری JSON همین اپ.
- **ویرایش:** انتخاب روی موج، زوم، کات/کپی/چسباندن/چسباندن میکسی، حذف، Crop، تکثیر، سکوت، فید، معکوس، نرمال‌سازی، مونو/استریو، Undo/Redo.
- **افکت‌ها:** گین، Pitch (با/بدون حفظ زمان)، سرعت بدون تغییر پیچ، فیلتر، EQ سه‌باند، دیستورشن، بیت‌کراشر، کورس/فلنجر، اکو، ریورب، ترمولو، کمپرسور؛ با پیش‌شنود.
- **خروجی:** MP3 (lamejs محلی در `vendor/`)، WAV و JSON شامل `audio` (WAV Data URI) و `recipe`؛ کتابخانه محلی (IndexedDB) و خروجی بانک JSON.
