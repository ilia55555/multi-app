استودیو افکت صدا

برای صدای لایه‌ای (مثل شلیک + پوکه)، یک صدا بساز، «جایگزینی زنده» را خاموش کن و صدای بعدی را با «میکس روی نشانگر» روی آن بنشان.

افکت‌ها روی بخش انتخاب‌شده اعمال می‌شوند؛ اگر چیزی انتخاب نشده باشد روی کل صدا.

    نحوه استفاده در بازی

    فایل JSON هر صدا شامل audio (WAV به‌صورت Data URI)، مدت، نرخ نمونه و دستور ساخت (recipe) است:

    const sfx = await fetch('gunshot.json').then(r => r.json());
const ctx = new AudioContext();
const buf = await ctx.decodeAudioData(
  await (await fetch(sfx.audio)).arrayBuffer());
function play() {
  const s = ctx.createBufferSource();
  s.buffer = buf; s.connect(ctx.destination); s.start();
}

    بانک JSON شکل {"sounds":[...]} دارد و همه صداهای کتابخانه را یک‌جا نگه می‌دارد.
