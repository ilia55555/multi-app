# Multi App Hub — مرکز اپلیکیشن‌ها

این مخزن یک ورودی مرکزی برای مجموعه‌ای از اپلیکیشن‌های مستقل است. داشبورد اصلی، فهرست اپ‌ها و مسیر ورود به هرکدام را در اختیار کاربر قرار می‌دهد.

## قانون ساختار پروژه

- هر پوشهٔ اپلیکیشن، یک اپ مستقل با مسئولیت و مستندات مخصوص خودش است.
- وقتی کاربر نام یک اپ را برای تغییر مشخص می‌کند، **فقط همان اپ** باید ویرایش شود و کد اپ‌های دیگر نباید تغییر کند.
- کد مشترکِ پوسته و صفحهٔ ورودی مرکزی در `src` قرار دارد؛ مستندات اختصاصی هر اپ در `apps/<app-name>` نگهداری می‌شود.
- برای اضافه‌کردن اپ جدید، کارت آن به صفحهٔ مرکزی افزوده و پوشهٔ مستقلش در `apps` ساخته می‌شود.

## اپلیکیشن‌های موجود

1. **StreamBox / استریم باکس** — پخش لینک مستقیم ویدیو همزمان با دریافت تدریجی، ذخیرهٔ نقطهٔ تماشا و تلاش مجدد پس از قطع اتصال.

## اجرا

```bash
npm install
npm run dev
```

## انتشار روی Netlify

پیکربندی انتشار داخل `netlify.toml` قرار دارد. در Netlify کافی است مخزن را از بخش **Add new site → Import an existing project** متصل کنید؛ تنظیمات Build و Publish به‌شکل خودکار خوانده می‌شوند:

- Build command: `npm run build`
- Publish directory: `dist`
- Node.js: نسخهٔ 22

اگر قبلاً سایت را با انتشار دستی پوشهٔ اصلی ساخته‌اید، آن Deploy را حذف کنید و مخزن را دوباره متصل کنید؛ فایل `index.html` توسعه مستقیماً قابل انتشار نیست و ابتدا باید Vite آن را داخل `dist` بسازد.

> پخش پیوسته به پشتیبانی سرور مبدأ از درخواست‌های HTTP Range و قالب قابل پخش در مرورگر وابسته است. ذخیرهٔ نقطهٔ پخش از پرش به ابتدای فیلم پس از اتصال مجدد جلوگیری می‌کند.
