# Multi App Hub — مرکز اپلیکیشن‌ها

این مخزن یک ورودی مرکزی برای مجموعه‌ای از اپلیکیشن‌های مستقل است. داشبورد اصلی، فهرست اپ‌ها و مسیر ورود به هرکدام را در اختیار کاربر قرار می‌دهد.

## قانون ساختار پروژه

- هر پوشهٔ اپلیکیشن، یک اپ مستقل با مسئولیت و مستندات مخصوص خودش است.
- وقتی کاربر نام یک اپ را برای تغییر مشخص می‌کند، **فقط همان اپ** باید ویرایش شود و کد اپ‌های دیگر نباید تغییر کند.
- فایل‌های سادهٔ پوسته و صفحهٔ ورودی در ریشه قرار دارند؛ کد و مستندات اختصاصی هر اپ در پوشهٔ مستقل همان اپ نگهداری می‌شود.
- برای اضافه‌کردن اپ جدید، کارت آن به صفحهٔ مرکزی افزوده و پوشهٔ مستقل آن ساخته می‌شود.

## اپلیکیشن‌های موجود

1. **Live Web Studio / لایو وب استودیو** — ویرایش پروژه و مشاهدهٔ زندهٔ خروجی وب.
2. **SecretChat / سکرت‌چت** — رمزگذاری، بازگشایی و انتقال فایل.
3. **نقشه‌کش** — ترسیم و اندازه‌گذاری دقیق روی بوم.
4. **استودیو پالت رنگ** — تولید، ویرایش و کپی پالت‌های رنگ.
5. **نمونه المان‌ها** — مرجع مستقل المان‌های HTML و کامپوننت‌های UI.
6. **StreamBox / استریم باکس** — پخش لینک مستقیم ویدیو همزمان با دریافت تدریجی و ذخیرهٔ نقطهٔ تماشا.
7. **RigidMesh Studio / استودیو مش صلب** — جابه‌جایی و چرخش بخش‌های مجزای مدل سه‌بعدی بدون تغییر رأس‌های هندسه.
8. **FrameFlow / فریم‌فلو** — برش خودکار شیت، پخش فریم‌های انتخابی و ساخت صحنهٔ دوبعدی چندلایه.

## اجرا و انتشار

پروژه هیچ وابستگی، Build step یا فریم‌ورکی ندارد و فقط از HTML، CSS و JavaScript ساده تشکیل شده است. برای اجرای محلی، ریشهٔ پروژه را با یک وب‌سرور استاتیک باز کنید:

```bash
python3 -m http.server 8080
```

برای Netlify مخزن را متصل کنید و **Build command را خالی** بگذارید؛ مقدار Publish directory باید `.` باشد. همچنین می‌توان کل پوشهٔ پروژه را مستقیماً در Netlify Drop رها کرد.

## PWA و نصب

صفحهٔ مرکزی Manifest را در مرورگر ایجاد می‌کند و `sw.js` فایل‌های پوسته و StreamBox را برای اجرای آفلاین ذخیره می‌کند. وقتی مرورگر شرایط نصب PWA را تأیید کند، دکمهٔ «نصب اپلیکیشن» در هدر ظاهر می‌شود. این دکمه پس از نصب یا هنگام اجرای نسخهٔ نصب‌شده مخفی است.

قابلیت قبلی آپلود و اجرای کد از داخل سایت، Netlify Functions، Netlify Blobs و تمام وابستگی‌های آن به‌طور کامل حذف شده‌اند. اضافه‌کردن اپ فقط با ایجاد پوشهٔ مستقل و Deploy نسخهٔ بررسی‌شده انجام می‌شود.

> پخش پیوسته به پشتیبانی سرور مبدأ از درخواست‌های HTTP Range و قالب قابل پخش در مرورگر وابسته است. ذخیرهٔ نقطهٔ پخش از پرش به ابتدای فیلم پس از اتصال مجدد جلوگیری می‌کند.
