GITHUB IMPORT

باز کردن پروژه از GitHub

لینک ریپو را وارد کن تا ساختار پوشه‌ها و همه فایل‌های Commit‌شده از برنچ انتخابی داخل استودیو باز شوند.

ریپوی Public بدون توکن باز می‌شود. برای ریپوی Private، Fine-grained token با دسترسی Contents: Read یا Read and write لازم است؛ توکن فقط در حافظه‌ی همین تب نگه داشته می‌شود.
دریافت ریپو از تنظیمات مشترک GitHub در هدر استفاده می‌کند؛ ریپو، برنچ و توکن را همان‌جا یک‌بار ذخیره کن.
فایل‌های زیرپوشه، فونت، تصویر و فایل‌های باینری هم دریافت می‌شوند. پوشه‌های .git و node_modules وارد نمی‌شوند.

GITHUB SYNC

ارسال تغییرات و ساخت Pull Request

فایل‌های فعلی، از جمله فونت و تصویر، روی یک برنچ جدا Commit می‌شوند و سپس Pull Request ساخته یا به‌روزرسانی می‌شود.

توکن فقط در حافظه‌ی همین تب نگه داشته می‌شود؛ در ZIP پروژه یا فایل‌های آن ذخیره نمی‌شود.
اتصال GitHub از پنل هدر خوانده می‌شود؛ این بخش فقط تنظیمات Pull Request مثل برنچ تغییرات، پیام Commit، عنوان و توضیحات را می‌گیرد.

SNAP WORKSPACE LAYOUT

چیدمان باکس‌های محیط کار

اول شکل باکس‌ها را انتخاب کن. سپس «فایل‌ها»، «ادیتور»، «نمایشگر» و «کنسول» را با Drag داخل جایگاه‌ها بینداز. روی موبایل، ابتدا یک پنل را لمس کن و بعد جایگاه مقصد را لمس کن.

باکس بزرگ با خط آبی مشخص است؛ هر کدام از چهار پنل را می‌توانی داخل آن قرار بدهی.
شکل باکس‌ها یک ساختار انتخاب کن
قرار دادن پنل‌ها بکش، رها کن یا لمس کن
نمونه کاربردی: برای «فایل‌ها سمت چپ، ادیتور بالا و نمایشگر پایین»، شکل باکس بزرگ سمت چپ را انتخاب کن و فایل‌ها را داخل باکس بزرگ، ادیتور را در باکس بالای راست و نمایشگر را در باکس پایین راست قرار بده.
